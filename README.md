## 先说清楚：这本书解决什么问题

大学是**从校园走向社会的过渡期**，也是信息差最贵的四年。

- 大一开学，报到、档案、户口、缴费，一个环节弄错就要跑三趟；
- 大二选课，不知道培养方案怎么算，白修一堆学分；
- 大三保研、考研、留学、考公同时开跑，不知道自己在哪条赛道上；
- 大四签三方、离校、档案、租房，办错一步影响很多年。

**没有人系统教过这些。**这本书把它们一件一件拆开，写成"今天就能做"的动作。

三个总原则：

> **先想清楚再选择 · 先保底线再谈发展 · 先查清楚再行动**

## 这本书适合谁

- **刚入学、还在适应环境的新生** —— 从报到第一天到第一学期结束，全都理顺
- **正在为学业、升学、就业焦虑的高年级同学** —— 卡在哪，就翻哪一篇
- **想把大学生活过得更条理、更有方向的人** —— 附录里的清单、时间线、模板直接用
- **辅导员、班主任、学长学姐、社团负责人** —— 拿去开班会、做入学教育、做分享（见下方"怎么用它"）

## 这本书不承诺什么

- **不构成投资建议、医疗诊断、法律意见或升学就业承诺。**
- **书里的政策、比例、金额、办理流程，都以学校通知、当地主管部门和官方渠道的最新规定为准。** 资助、医保、贷款、入伍、就业这类事项，办理前请向学校对应部门核实。
- 涉及合同、纠纷、健康、大额支出，请与家长、老师或专业人士核实后再执行。

**政策会变，方法不会。**这本书给的是判断框架和办事路径，不是当年口径的复制品。

## 一条建议长什么样

全书每一条都按同一套体例写：

> **建议正文 · 为什么有效 · 依据来源 · 案例参考 · 怎么做**

不只告诉你"要做什么"，还告诉你"为什么这么做"、"依据在哪"、"别人踩过什么坑"，最后落到 3–4 步具体动作上。

> ### 档案按统一渠道转递，不要自己拆封
> **【避坑·止损】** 防止档案失效
>
> 高中档案、党团关系按学校要求通过机要或统一渠道转递，**不要自行拆封、长期揣在手里**；团员按时到学校团组织报到登记，党员组织关系在有效期内转接。
>
> **为什么有效：** 这条属于止损项——真正的成本往往不是眼前花出去的钱，而是被套进去之后消耗的时间、情绪、信誉与机会。
>
> **怎么做：**
> ① 档案走统一转递渠道
> ② 不拆封、不私自保管
> ③ 按时登记党团关系
> ④ 保留转递回执与凭证

### 四类标签，标清代价

| 标签 | 含义 |
| :--- | :--- |
| **【零成本·立刻做】** | 不用花钱，今天就能开始 |
| **【每天十分钟】** | 小投入，长期复利 |
| **【长期复利】** | 短期看不到，三年后见差距 |
| **【避坑·止损】** | 少走弯路，就是加速 |

## 大学四年，每个阶段该推进什么

附录七给出的通用节奏（不同专业、学制、目标会有差异，节点以本校通知为准）：

| 阶段 | 关键动作 |
| :--- | :--- |
| **大一上** | 熟悉校规与培养方案，稳住第一学期绩点，适应作息与自习节奏，加入一两个兴趣社团，准备四级首考 |
| **大一下** | 了解本专业出路与转专业规则，明确一项可积累的技能，建立记账与信息渠道习惯，参加一次竞赛或志愿 |
| **大二上** | 打牢专业基础课，关注对口实习与科研方向，考取计划内基础证书，维护宿舍与同学关系 |
| **大二下** | 争取第一段对口实习或项目经历，确定升学/就业大致倾向，梳理成绩单、简历初稿与素材库 |
| **大三上** | 收敛主攻方向（保研/考研/留学/考公/就业），按目标准备材料、考试与作品，保持成绩与综测达标 |
| **大三下** | 完成夏令营、实习、网申或备考关键动作，打磨简历与面试素材，关注选调、校招和专项报名窗口 |
| **大四上** | 推进秋招、推免或考研报名，落实去向，比较 offer 与录取结果，签约前核对合同与三方条款 |
| **大四下** | 完成毕业论文与答辩，办清离校、档案户口、党团关系转接，做好租房、入职或升学衔接 |

**这张表最有用的地方是：让你知道"现在该干什么"，而不是等到大三才发现前两年空着。**

## 关于"可追溯"与时效

本书坚持**可追溯**原则：凡引用政策与数据处，均注明发布机构与公开链接；案例为公开报道与日常同类情形的归纳，用于说明道理，不指向具体个人。

同时要说清楚一件事：**这本书里的政策是会过期的。**

奖助学金、医保、助学贷款、入伍、就业见习、三方协议、档案转递等规定，**每年都可能调整**。书里的比例、金额、流程是编制时的公开口径，办理前请务必向学校对应部门（学生资助管理中心、校医院、武装部、就业指导中心、教务处、保卫处等）或当地主管部门核实，**以最新官方发布为准**。
